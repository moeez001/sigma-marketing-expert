# Sigma Marketing Expert

A modern and responsive front-end website for **Sigma Marketing Expert** — a real-world marketing and consulting agency.

This site is designed to showcase the agency’s services, engage visitors, and allow users to easily request consultations or get in touch. It features smooth animations, a dark-themed aurora borealis background, and scroll-triggered interactive UI elements.

## 📌 Features

- 🌌 Aurora borealis-style dark background with AI/neural-inspired lighting
- 🎬 Animated "Sigma" logo intro on page load
- 📜 Scroll-based animations for all page sections
- 🛠️ Services section with descriptions and CTAs
- 📞 Consultation & contact forms with validation
- 📱 Fully responsive across devices
- 📧 Optional email integration using Nodemailer (Node.js)

---

## 🛠️ Tech Stack

- **Languages**: HTML5, CSS3/SCSS, TypeScript
- **Framework**: Node.js (Express.js structure for future backend)
- **Optional Tools**: Tailwind CSS, Bootstrap, React (optional), Vite/Webpack
- **Deployment Ready**: GitHub Pages / Netlify
